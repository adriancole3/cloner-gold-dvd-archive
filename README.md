## What is DVD Cloner Gold?

DVD Cloner Gold gives you a single place to copy and keep optical media when you work with both DVD and Blu-ray. Copy paths, ISO output, and checks you can trust sit in one workflow, whether you need a quick backup or a longer-lived archive.

It fits collectors, library maintainers, and anyone who runs the same copy jobs again and again. Batch queues, metadata that stays with the disc data, and structured verification help you stay organized on larger runs without losing useful disc details along the way.

## How to use it

A common path through the tool:

1. Load or insert the source disc.
2. Pick a straight disc-to-disc copy, ISO output, or an archive-style job.
3. Check the scan output and any metadata the tool found.
4. Queue extra tasks when several discs need processing.
5. After the copy, run verification if you want checksum confirmation.
6. Export checksums or kept metadata for your records.

The same steps work across DVD and Blu-ray sets, so naming, verification, and archive notes stay consistent from disc to disc.
